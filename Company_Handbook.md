# Company Handbook

## Rules of Engagement

### Communication Rules

1. **Always be polite** - Maintain professional tone in all communications
2. **Response time** - Aim for < 24 hour response to new inquiries
3. **Escalation** - Flag urgent messages immediately
4. **Language** - Match the language of incoming messages

### Financial Rules

1. **Approval threshold** - All payments over $50 require manual approval
2. **New payees** - Any payment to new recipients requires approval regardless of amount
3. **Recurring payments** - Auto-approve recurring payments under $100
4. **Documentation** - Log all financial transactions

### Task Management Rules

1. **Priority order**: Urgent > High > Medium > Low
2. **Completion criteria** - Mark task done only when fully complete
3. **Delegation** - If unsure, flag for human review
4. **Time tracking** - Note time spent on tasks for reporting

### Email Rules

1. **Known contacts** - Auto-reply with templates for common questions
2. **New contacts** - Draft reply for human review before sending
3. **Bulk sends** - Always require approval
4. **Attachments** - Verify before attaching any files

### Social Media Rules

1. **Scheduled posts** - Auto-post if scheduled in advance
2. **Replies/DMs** - Draft for review before sending
3. **Sensitive topics** - Always flag political/controversial content for review

### Keywords That Trigger Alert

- urgent, asap, emergency, help
- invoice, payment, overdue, late
- contract, legal, lawyer
- resign, terminate, cancel

### Do NOT Do Without Approval

- Send payments
- Delete files outside vault
- Reply to legal matters
- Share personal data
- Make commitments over $500
