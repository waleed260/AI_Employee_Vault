# SKILL.md - Update Dashboard

## Purpose
Keep the Dashboard.md current with accurate status information.

## Trigger
- After any significant action
- On schedule (every 15 minutes via orchestrator)
- Manual: "Update Dashboard"

## Update Process

1. **Count** items in each folder:
   - `/Needs_Action`: pending count
   - `/Pending_Approval`: awaiting count
   - `/Done`: completed today count
   - `/Logs/`: action count today

2. **Calculate** metrics:
   - Tasks completed this week
   - Average response time
   - Pending items by priority

3. **Check** external data:
   - Bank balance (if configured)
   - Active projects status

4. **Write** updated Dashboard.md

## Dashboard Template

```markdown
---
created: 2026-01-01
last_updated: {timestamp}
---

# AI Employee Dashboard

| **Pending Tasks** | {count} | {time} |
| **Awaiting Approval** | {count} | {time} |

| Service | Status |
|---------|--------|
| Orchestrator | Running/Stopped |
| Gmail Watcher | Running/Stopped |

{last 5 actions}
```

## Success Criteria
- Dashboard reflects current state
- All counts accurate
- Timestamps current
