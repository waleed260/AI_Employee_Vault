# SKILL.md - Analytics & Reporting

## Purpose
Generate business intelligence, track performance metrics, and create reports.

## Trigger
- Manual: "Generate report", "Show analytics"
- Automated: Scheduled reports (daily, weekly, monthly)

## Workflow

### 1. Collect Metrics
- Email statistics (inbox, sent, read/unread)
- Task completion rates
- Workflow distribution
- Action history

### 2. Analyze Data
- Trend analysis
- Performance indicators
- Team productivity
- Business health

### 3. Generate Reports
- Daily summary
- Weekly briefing
- Monthly review
- Custom reports

### 4. Save & Notify
- Save reports to `/Briefings/`
- Update Dashboard
- Notify stakeholders

## Commands

```
# Generate reports
Generate daily report
Generate weekly report
Generate monthly report

# Show analytics
Show email analytics
Show task analytics
Show workflow analytics

# Dashboard
Show dashboard
Update dashboard

# Export
Export analytics to CSV
```

## Report Types

### Daily Report
- Tasks completed yesterday
- Emails processed
- Time-sensitive items
- Today's priorities

### Weekly Briefing (Monday Morning CEO)
- Week in review
- Pending approvals
- Upcoming tasks
- Business metrics
- Recommendations

### Monthly Review
- Goals vs actuals
- Revenue/expense summary
- Team performance
- Strategic insights

## Metrics Tracked

### Email Metrics
- Total emails
- Unread count
- Top senders
- Response rate

### Task Metrics
- Pending tasks
- Completed tasks
- Completion rate
- Average completion time
